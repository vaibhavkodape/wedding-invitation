# Project Saptapadi
## Design Bible

Version: 2.0

---

# Philosophy

Project Saptapadi is **not** a wedding website.

It is a luxury digital invitation.

The experience should feel like opening a handcrafted royal keepsake.

The website should tell a story, not simply present information.

---

# Core Principles

1. Simplicity over decoration.
2. Luxury through restraint.
3. Motion should feel natural.
4. Every animation must have a purpose.
5. Every component must be reusable.

---

# Lighting

Only two light sources exist.

## Moonlight

- Cool
- Soft
- Blue

## Palace Gold

- Warm
- Soft
- Inside the invitation

No other coloured lights should be introduced.

# Typography

## Cinzel

Headings

## Montserrat

Body

## Great Vibes

Very limited usage.

# Motion

Animations should feel

- Heavy
- Smooth
- Slow
- Elegant

Never use

- Bounce
- Elastic
- Flash
- Spin

Preferred motion

- Fade
- Lift
- Rotate
- Depth
- Light

---

# Intro Experience

The invitation cover is the interface.

There is no visible Hero initially.

Sequence

1. Moonlight
2. Invitation
3. Wax Seal
4. Touch
5. Seal Press
6. Pause
7. Light Leak
8. Flap Opens
9. Invitation Revealed
10. Hero Appears

---

# Hero

The Hero should feel like entering the world hidden inside the invitation.

The Hero is revealed, not loaded.

---

# Storytelling

Each section is a chapter.

The user should feel like progressing through a story.

---

# Component Rules

Every component should have one responsibility.

Avoid duplicated CSS.

Avoid section-specific styling whenever a reusable component can be created.

---

# Performance

Target

60 FPS

No unnecessary libraries.

Theme-aware.

Responsive.

Accessible.

---

# Project Goal

Visitors should not think

"This is a nice wedding website."

They should think

"I've never experienced a wedding invitation like this."
