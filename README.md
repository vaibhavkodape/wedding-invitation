# Project Saptapadi

A luxury cinematic digital wedding invitation built with HTML, CSS, and Vanilla JavaScript.

---

## Vision

Project Saptapadi is not designed as a traditional wedding website.

It is a handcrafted digital experience inspired by luxury brands such as Rolls-Royce, Cartier, Aman Resorts and Apple.

The goal is to make every visitor feel like they are opening a premium royal wedding invitation.

---

## Theme

Primary Colors

---

## Technology

- HTML5
- CSS3
- Vanilla JavaScript

No frameworks.

No Bootstrap.

No jQuery.

## Features

- Cinematic Opening Experience (V2 – In Progress)
- Hero Section
- Saptapadi Story
- Wedding Timeline
- Live Countdown
- Gallery
- Venue & Google Maps
- RSVP via WhatsApp
- Add to Calendar (.ics)
- Background Music
- Responsive Design
